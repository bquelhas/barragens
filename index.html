        Como usar

        1. Clica num ponto colorido (barragem) para ver os detalhes.
        2. Usa Camadas para mostrar/ocultar albufeiras, centrais, linhas elétricas, etc. Algumas só aparecem com mais zoom.
        3. Usa Filtros para ver só Portugal, só um tipo de uso, ou só barragens com página Notion.
        4. Procura pelo nome no topo; clica num resultado para voar até lá.

        Ligar uma barragem ao Notion

        Cada barragem tem um ID Mapa (ex.: way/123456). No Notion, cola esse ID na propriedade de texto ID Mapa da página da barragem. Também podes colar o link completo do OpenStreetMap — o script normaliza por ti.

        O URL desta página guarda o estado (barragem selecionada, posição e zoom), por isso podes partilhá-lo.
