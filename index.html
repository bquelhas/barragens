        Destaques

        Dados do OpenStreetMap. Clique numa barragem para ver a ficha, e em “Camadas” / “No mapa” para explorar.

        Como usar

        1. Clica num ícone de barragem para abrir a ficha.
        2. Usa Camadas para mostrar/ocultar albufeiras, centrais, rede elétrica, etc. (algumas só a partir de certo zoom).
        3. Usa Filtros para ver só Portugal, só um tipo de uso, ou só barragens com página Notion.
        4. Ao selecionar, destaca-se a albufeira e a rede elétrica relacionada (a âmbar).
        5. A aba No mapa lista as barragens visíveis; clica para voar até lá.

        Ligar uma barragem ao Notion

        Na ficha de cada barragem há um ID Mapa (ex.: way/123456). Cola esse ID na propriedade ID Mapa da página no Notion (também podes colar o link completo do OpenStreetMap).
